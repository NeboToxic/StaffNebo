# NeboProject 1.3.0

Мониторинг latest.log Cristalix, скриншоты и уведомления Telegram/VK для Windows.

## Запуск
Распакуйте Windows-архив и запустите NeboProject.exe. Python не требуется.
Укажите ник, latest.log и реквизиты сервиса. Telegram-боту нужны доступ к чату и права отправки. Для VK укажите свой ID получателя и токен с нужными правами.
Кнопка «Центр» открывает дополнительные возможности.

## Центр управления
1. История SQLite: ник, причина, дата, скриншот, профиль и результат доставки; поиск, фильтры, CSV. Таблица показывает до 1000 строк; экспорт включает все строки по фильтру.
2. Неотправленные: постоянная очередь, ошибки и ручной повтор. После перезапуска незавершённые задания остаются в очереди. По умолчанию повтор использует исходного получателя. Применение текущих настроек и отправка текста без отсутствующего фото выбираются явно.
3. Подключение: проверка Telegram/VK и Telegram-прокси, понятные ошибки сети и доступа. Проверка не отправляет сообщение; доступность API не гарантирует последующую доставку.
4. Профили: независимые ники, журналы, получатели и настройки. Для переключения нужен существующий файл журнала.
5. Уведомления: выбор событий и фото, шаблон и предпросмотр. Поля: {target}, {type}, {reason}, {date}, {time}, {moderator}, {profile}. Поле {profile} содержит ник профиля.
6. Захват: весь рабочий стол, выбранный монитор или клиентская область видимого окна по части заголовка. Окно должно быть не свёрнуто и не перекрыто другими окнами. Можно скрывать интерфейс приложения перед захватом.
7. Секреты: Windows DPAPI защищает токены и пароль прокси в базе, профилях и очереди; значения скрыты, есть удаление из всех сохранённых настроек. База привязана к учётной записи Windows; после переноса может понадобиться повторный ввод токенов.
8. Статистика: день, неделя, частые причины и процент успешных доставок среди завершённых попыток. Сохраняется между запусками; доступен фильтр активного профиля.
9. Диагностика: JSON с версией, зависимостями, состоянием мониторинга и ошибками без токенов. Перед публичной публикацией проверьте отчёт на личные пути и данные.
10. Обновления: публичный GitHub Release, скачивание после подтверждения и проверка SHA-256. Автоматической установки нет. После публикации задайте owner/repository. Релиз должен содержать *-Windows.zip и SHA256SUMS.txt.

Данные: %APPDATA%/NeboProject/neboproject.db; изображения: %APPDATA%/NeboProject/screenshots.
NEBO_DATA_DIR задаёт отдельную папку данных. Не публикуйте базу и скриншоты. Старые внешние копии настроек и резервные копии автоматически не удаляются.
Успешно отправленные изображения сохраняются по умолчанию; это можно отключить.
Режим «В трей» скрывает кнопку панели задач при доступном значке. Выход ждёт завершения сетевых запросов.
Повтор выполняется пользователем. Telegram при неоднозначном сетевом сбое может доставить сообщение повторно; VK использует сохранённый random_id.

## Исходники
Python 3.12 x64, Windows:

    python -m venv .venv
    .venv/Scripts/activate
    python -m pip install -r requirements-lock.txt
    python main.py
    python run_tests.py

Тесты используют изолированные данные и заглушки HTTP. Реальная доставка требует ваших токенов и прав.
Сборка: build_windows.bat и BUILD_README.txt. Публикация: GITHUB_SETUP.md.
