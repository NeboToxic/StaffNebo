# 1.3.0

История и CSV, постоянная очередь доставки, проверка подключения, профили, шаблоны, захват монитора/окна, Windows DPAPI, статистика, диагностика и обновления GitHub. Центр управления с девятью страницами, 23 новых теста и workflow релизов.

# Изменения 1.2.3

- Восстановлены создание трея и пункт выхода; при недоступном трее окно остаётся в панели задач. Повторные попытки ограничены.
- Ошибка захвата или сохранения скриншота освобождает очередь и позволяет обработать следующее событие.
- Монитор ждёт завершения строк, сохраняет порционные UTF-8 символы и обнаруживает пересоздание/перезапись latest.log.
- Парсер требует полного совпадения ника и экранирует ники/теги в Telegram HTML. Причина и остальные сырые поля также экранируются.
- Исправлены маскирование Telegram-токена и аутентификации прокси в ошибках, поддержка отрицательных Telegram ID, проверка диапазона порта и IPv6 прокси.
- VK делает три попытки отправки скриншота; идентификатор сообщения сохраняется между повторами, отмена прекращает последующие попытки.
- Проверка VK не обращается к Telegram. Новые настройки и автозапуск сохраняются после успешной проверки.
- Отправка Telegram выполняется с явными тайм-аутами и индивидуальным прокси, без глобального состояния SDK. Длинная причина отправляется отдельными текстовыми частями.
- Ошибка удаления уже отправленного файла не вызывает повторной доставки. Неотправленные скриншоты не удаляются при выходе.
- Удалён принудительный os._exit; окно ждёт завершения QThread. Отмена прерывает ожидание между попытками.
- Горячая клавиша передаётся в GUI через сигнал. Логи экранируются для QTextEdit; имена скриншотов уникальны.
- Устранён сбой Qt при запуске и сборке из путей с кириллицей. Существующий spec сохранён в контролируемых файлах; сборка останавливается при ошибке установки или тестов.
- Обновлены регрессионные тесты и добавлена проверка настоящих окон, валидации, очереди и завершения потоков.
- Исправлено обрезание заголовка на узком окне; статус обозначает мониторинг, а не подтверждённое соединение с API.

Важно: первый отчёт ошибочно отмечал отсутствие spec из-за .gitignore. Spec присутствовал в исходном архиве; фактический дефект сборки был связан с путями Qt.
