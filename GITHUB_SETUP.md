# Публикация на GitHub

1. Распакуйте Source.zip. Корень репозитория — папка с main.py, README.md и NeboProject.spec.
2. Создайте репозиторий и загрузите исходники, включая скрытую папку .github. Базы, скриншоты, токены и локальное окружение не загружайте; основные исключения включены в .gitignore.
3. Выберите лицензию, если хотите разрешить стороннее использование. Лицензия не назначена без решения автора.
4. Во вкладке Actions разрешите Build and release. Ручной запуск сохраняет архивы как артефакты.
5. Отправьте тег v1.3.0. Workflow проверит совпадение с VERSION, выполнит тесты, соберёт EXE и опубликует Release с Windows ZIP, Source ZIP и SHA256SUMS.txt. Следующие теги должны совпадать с версией в config.py.
6. В настройках обновлений приложения задайте owner/repository. Требуется публичный опубликованный релиз.

Workflow использует стандартный GITHUB_TOKEN; токены Telegram/VK ему не нужны.
Подпись EXE сертификатом автора не настроена: Windows может показать предупреждение об неизвестном издателе.
SHA-256 выявляет повреждение файла. Контрольная сумма находится в том же релизе, поэтому доверие к обновлениям зависит от защиты GitHub-аккаунта.
